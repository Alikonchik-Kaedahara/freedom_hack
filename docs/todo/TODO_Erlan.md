2. Модель, которая целиком помещается в 8 ГБ видеопамяти:

- [ ] `ollama list` показывает модель
- [ ] сон компьютера выключен (Параметры → Система → Питание → «Никогда»)

### 2. Cloudflare Tunnel (10 мин)

У Ollama нет пароля, поэтому **сам порт 11434 наружу не открываем**: `OLLAMA_HOST=0.0.0.0` и `OLLAMA_ORIGINS=*`
не задавать. Туннель ведёт на релей `tools/ollama_relay.py` (127.0.0.1:11435): он требует токен и пропускает только
`GET /api/tags` и `POST /api/chat`.

1. Установить `cloudflared`: `winget install --id Cloudflare.cloudflared`.
2. Запустить всё одной командой (Ollama уже должна работать):

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\start_local_stack.ps1
```

При первом запуске скрипт создаст `.env.relay` с токеном (файл в `.gitignore`). В выводе появится адрес
`https://слова-через-дефис.trycloudflare.com`. Окно не закрывать: туннель и релей работают, пока оно открыто, Ctrl+C останавливает оба.

3. Проверить снаружи: `https://…trycloudflare.com/api/tags` без токена → 401 (так и должно быть);
   `curl -H "Authorization: Bearer <токен>" https://…/api/tags` → JSON со списком моделей.

- [ ] адрес туннеля получен и проверен снаружи (401 без токена, 200 с токеном)
- [ ] адрес и токен переданы Алихану лично (не в git, не в общий чат)

Быстрый туннель даёт новый адрес при каждом запуске. После перезапуска нужно обновить `CQA_LOCAL_RELAY_URL` на Railway.
Новый токен: `tools\start_local_stack.ps1 -NewToken` (тогда обновить и `CQA_LOCAL_RELAY_TOKEN`).

Поле «Адрес сервера» в интерфейсе тогда не используется. «Модель» → «Локальная модель», Модель = `qwen2.5:7b`.
Статус должен стать «Ollama подключена». Оценить один чат (любой RU), убедиться, что движок local, засечь время.
