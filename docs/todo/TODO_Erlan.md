# Ерлан — что делать сейчас

Твоя зона: локальная модель на своём компьютере (RTX 3070 Ti, 8 ГБ видеопамяти; Ryzen 7800X3D; 32 ГБ) и сравнение её с облаком. Это пункт, которым можно пожертвовать, если не успеваем, — но если он получится, это сильный аргумент на защите: «переписка клиентов не покидает контур компании».

## 1. Ollama и модель (20 мин, пока качается — делать пункт 2)

1. Установить Ollama с ollama.com, перезагрузить терминал.
2. Скачать модель, которая целиком помещается в 8 ГБ видеопамяти:

```
ollama pull qwen2.5:7b
ollama list
```

Если в каталоге Ollama есть более новая модель семейства Qwen или Gemma размером 7–9B — можно взять её; главное, чтобы файл был меньше ~5,5 ГБ. 14B (`qwen2.5:14b`, ~9 ГБ) скачать только как эксперимент на потом: на этой видеокарте она считает в 5–8 раз медленнее.

- [ ] `ollama list` показывает модель

## 2. Проект на своём компьютере (15 мин)

```
git clone https://github.com/Alikonchik-Kaedahara/freedom_hack
cd freedom_hack
python -m venv .venv
.venv\Scripts\activate            # Windows; на Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
copy .env.example .env            # Windows; иначе cp
```

В `.env` вписать `CQA_DATA_API` (ссылку даст Томирис) и `CQA_TEAM_NAME`. Ключ Claude не нужен.

Запуск так, чтобы ноутбуки видели сервер по сети:

```
set HOST=0.0.0.0                  # Windows; на Linux/Mac: export HOST=0.0.0.0
python server.py
```

Узнать свой адрес в сети (`ipconfig` → IPv4, вида 192.168.x.x) и скинуть команде: `http://192.168.x.x:8000`. Если не открывается с другого ноутбука — разрешить Python в брандмауэре Windows.

- [ ] сервер открывается с другого компьютера по сети
- [ ] импорт `DEV` прошёл (65 диалогов)
- [ ] экран «Модель» → «Локальная модель» → статус «Ollama подключена», модель найдена

## 3. Пробная оценка (10 мин)

Оценить один русский и один казахский чат локальной моделью. Посмотреть:

- время на диалог (ожидается 20–30 с для 7–8B);
- не появляются ли пометки «требует проверки» — это значит, модель не прошла проверку доказательств после трёх попыток;
- читаемы ли объяснения на русском.

- [ ] время на диалог записано в `КАЛИБРОВКА.md` (раздел «Тайминг»)

## 4. Бенчмарк (после того, как команда выберет 12 чатов, 30 мин)

1. Получить список 12 ID и ручные оценки из `КАЛИБРОВКА.md`.
2. Оценить эти 12 чатов локальной моделью (Диалоги → выбрать галочками → «Оценить выбранные»).
3. Заполнить в таблице калибровки колонку «local» по каждому критерию и посчитать совпадения с ручной оценкой: отдельно по RU, EN, KZ.
4. Сравнить с колонкой «cloud», которую заполнит Томирис.

Решение по итогу — только по цифрам:

- local не хуже cloud на RU и EN → можно маршрутизировать: RU/EN локально, KZ в облако (это доработка, о ней скажи Томирис);
- local хуже везде → облако для всего, локальную модель показать на защите на двух диалогах как опцию.

- [ ] таблица заполнена, вывод записан

## 5. Если осталось время: 14B на казахском (30 мин)

`ollama pull qwen2.5:14b`, выбрать её на экране «Модель», оценить 4 казахских чата из бенчмарка, сравнить с 7B. Замерить время на диалог — оно решает, годится ли она для часа контроля (10 чатов должны уложиться в 20–30 минут с запасом).
