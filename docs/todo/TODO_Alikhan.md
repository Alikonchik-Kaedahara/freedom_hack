# Алихан — что делать сейчас

Твоя зона: интерфейс, хостинг, сдача. Начинать после сообщения Томирис «main обновлён».

## 1. Обновиться и проверить сборку (10 мин)

```
git checkout main
git pull
pip install -r requirements.txt -r requirements-dev.txt
python manage.py update-defaults
python manage.py test        # 50 passed, # pass 13
```

- [ ] тесты зелёные локально
- [ ] во вкладке Actions на GitHub последний коммит зелёный

## 2. Хостинг (30 мин)

Переменные окружения на площадке (Railway / Render / что выбрали):

- `CQA_DATA_API` — ссылка GET из задания целиком;
- `ANTHROPIC_API_KEY` — ключ Claude;
- `CQA_STORAGE_DIR` — путь к постоянному диску (например `/data`), иначе оценки и апелляции пропадут при перезапуске;
- `CQA_TEAM_NAME` — название команды.

Проверить:

- [ ] `GET /healthz` отвечает `{"ok": true}`
- [ ] интерфейс открывается по публичной ссылке, импорт `DEV` проходит
- [ ] после перезапуска сервиса оценки на месте (диск подключён)
- [ ] `python server.py --demo` локально поднимает демо без ключа — на случай, если хостинг ляжет на защите

## 3. Прокликать интерфейс на реальном DEV (40 мин)

Жюри может сесть за ноутбук и несколько минут клацать само. Пройти как чужой человек, каждый экран:

- [ ] Обзор: KPI, «Требуют внимания» со спорными критериями, фильтр по языкам
- [ ] Диалоги: фильтры «Грубая ошибка», «Апелляция», «Спорные», поиск; кнопка «Выгрузить» — модалка с отчётом и скачиванием
- [ ] Карточка: клик по доказательству прокручивает к реплике; метки «Низкая уверенность» / «Требует проверки»; строка с моделью и стоимостью под итогом; N/A с причиной; секции
- [ ] Звонки: все 5 записей DEV играют, переход по таймкоду попадает в реплику. Если какая-то не грузится — показать ссылку «открыть запись» и вписать в README в «Ограничения»
- [ ] Апелляции: подать → решить → итог пересчитался, исходная оценка видна
- [ ] Чек-листы: добавить критерий, поменять вес (сумма 100 держится), поле «Код в выгрузке», сохранить версию, «Применить», сравнение «было → стало»
- [ ] Модель: три движка, стоимость, поле названия команды
- [ ] Импорт: загрузка файла JSON (взять `demo/sample/dataset.json`)
- [ ] Мобильная версия: карточка и апелляции

Всё, что сломано или выглядит неаккуратно, — чинить сейчас. Визуально держать корпоративный стиль: никаких иконок-персонажей, игровых элементов, лишних анимаций (организаторы предупредили прямо).

## 4. Сдача (15 мин)

- [ ] ссылку на открытый репозиторий отправить организаторам сегодня
- [ ] README: раздел «Деплой» актуален, публичный адрес вписан
- [ ] в репозитории нет `.env`, `storage/`, патчей

## 5. Сценарий защиты (20 мин)

Выбрать из DEV и записать ID в `README` (раздел «Сценарий защиты»):

- [ ] чат с N/A по идентификации (общий вопрос) — показать перераспределение веса
- [ ] чат с «Нет» и проверенным участком (нет приветствия / нет прощания)
- [ ] чат с грубой ошибкой (p1-ru-009, p1-kz-015 или p1-en-014 — данные о счёте без идентификации)
- [ ] звонок с рабочим плеером
- [ ] спорный критерий для апелляции

И четыре сценария, которые организаторы обещали спрашивать: все диалоги с грубыми ошибками + объяснения; подача апелляции; изменение критерия и веса; разбор одного диалога с обоснованием. На каждый — кто кликает, кто говорит.
