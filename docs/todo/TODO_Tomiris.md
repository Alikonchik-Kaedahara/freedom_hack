# Томирис — что делать сейчас

Порядок важен: пункты 1–3 — обязательная часть сдачи, без них остальное не имеет смысла.

## 1. Влить патч с выгрузкой результатов (15 мин)

Файл `results-export.patch` положить в папку `freedom_hack`, затем в терминале:

```
git checkout main
git pull
git log --oneline -1            # ожидается 942d8d9 Prepare for hosting… или новее
git checkout -b results-export
git am -3 results-export.patch  # ожидается «Applying: Выгрузка results.json…» без ошибок
python3 manage.py update-defaults   # chat-base: версия 2, call-base: версия 2
python3 manage.py test              # 50 passed, # pass 13
git push -u origin results-export
git checkout main
git merge results-export
git push
rm results-export.patch
```

Если `git am` остановился: `git am --abort` и прислать вывод в чат.

- [ ] патч в main
- [ ] тесты зелёные
- [ ] написать Алихану и Ерлану «main обновлён, делайте git pull»

## 2. `.env` и название команды (10 мин)

```
cp .env.example .env
open -e .env
```

- `CQA_DATA_API=` — полная подписанная ссылка GET от организаторов. Сохранить её в локальном файле `.env`.
- `ANTHROPIC_API_KEY=` — ключ Claude (или ввести на экране «Модель»).
- `CQA_TEAM_NAME=` — настоящее название команды (попадает в `team_name` файла результатов).

Запуск: `python3 server.py` → http://localhost:8000.

- [ ] импорт `DEV` работает (65 диалогов)
- [ ] на экране «Модель» выбран облачный движок, статус «Ключ API задан»

## 3. Прогнать DEV, выгрузить, сохранить снимок (30 мин)

1. Диалоги → «Оценить 65 диалогов». Около 5 минут, около 5 $.
2. Обзор → «Требуют внимания»: открыть все спорные критерии и грубые ошибки, прочитать объяснения. Если видны явные ошибки модели — записать в файл калибровки (см. `КАЛИБРОВКА.md`), не править на ходу.
3. Диалоги → «Выгрузить» → `results/dev`. В отчёте должно быть `ok 65, error 0`, «Формат проверен: проблем нет».
4. В терминале:

```
python3 manage.py check dev
python3 manage.py snapshot
git add results/dev/results.json demo/snapshot
git commit -m "DEV results and demo snapshot"
git push
```

- [ ] `results/dev/results.json` в репозитории, 65 записей, error 0
- [ ] `demo/snapshot/` в репозитории
