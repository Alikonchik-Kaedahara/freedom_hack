## Осталось — по приоритету

### 1. Влить ветку с новыми функциями (10 мин)

```
cd ~/freedom_hack
git checkout main && git pull
git checkout -b features
git am -3 features.patch
python3 manage.py test                # 77 pytest + 14 node, все зелёные
python3 manage.py update-defaults     # трактовки правил → чек-листы версии 3 в твоём хранилище

git push
```

На Railway ничего дополнительно запускать не нужно: трактовки стартовых правил подставляются в старые чек-листы при
чтении, карточка и отчёт берут их из текущего чек-листа, если в оценке их нет. `update-defaults` локально — чтобы
трактовки легли в хранилище новой версией и были видны в истории версий.
