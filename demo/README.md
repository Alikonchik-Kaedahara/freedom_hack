# demo/ — данные для демонстрации без ключа

## sample/ — синтетические диалоги

`dataset.json` — пять выдуманных диалогов в формате API организаторов (RU, KZ, EN чаты и один звонок без записи).
Имена, тарифы и цифры в них условные. `answers.json` — ответы оценки по стартовым чек-листам «Чаты» (`chat-base`)
и «Звонки» (`call-base`), которые движок replay возвращает вместо модели.

Что показывает каждый диалог:

| ID | Что демонстрирует | Итог |
|---|---|---|
| `sample-ru-001` | Идеальный чат; критерий 03 — N/A (общий вопрос о тарифах), вес перераспределён | 100 |
| `sample-ru-002` | «Нет» с проверенным участком (нет приветствия, нет идентификации, нет прощания); критерий 05 с низкой уверенностью — спорный, кандидат на апелляцию | 40,5 → после принятой апелляции по 05: 55,5 |
| `sample-kz-003` | Казахский язык; идентификация подтверждена системным событием; пауза без предупреждения — 7 из 10 | 95,5 |
| `sample-en-004` | Английский язык; грубая ошибка — платная услуга в обход компании (флаг); вопрос клиента закрыт частично | 87,5 + флаг |
| `sample-call-005` | Звонок (ISO-метки времени, скрытые данные); критерий 02 — N/A | 100 |

Загрузить: в интерфейсе ввести `group_id` = `SAMPLE`, либо `python manage.py load-sample`, либо загрузить
`sample/dataset.json` файлом через «Загрузить файл».

## snapshot/ — снимок реальных оценок

`python manage.py snapshot` копирует сюда наборы, результаты и чек-листы из `storage/` (ключи API не копируются).
Закоммитьте папку — тогда `python server.py --demo` восстановит оценки на любой машине, а движок replay
воспроизведёт их без обращения к модели.
